# i18n EN Home Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Marketing-One-Pager unter `/` (DE) und `/en` (EN) mit Dictionary-Merge, Nav-Toggle und korrektem `html lang` — Rechtsseiten bleiben DE-only.

**Architecture:** Leichte Dictionaries (`de.ts` / `en.ts` mit `satisfies Dictionary`). Sprachneutrale Assets/IDs bleiben in `constants.ts`. Server-Pages laden `getDictionary(locale)`, mergen per `id`, reichen Props an `HomePage` und Sections. `/en` bekommt blocking Inline-Script für `document.documentElement.lang="en"`. Kein i18n-Framework, kein Cookie, kein GSAP-Umbau.

**Tech Stack:** Next.js 16 App Router, React 19, TypeScript, pnpm — existing stack only.

**Spec:** `docs/superpowers/specs/2026-08-12-i18n-en-home-design.md`

## Global Constraints

- Locales: nur `"de"` | `"en"`; Default `/` = DE, EN = `/en`
- Rechtsseiten `/agb`, `/datenschutz`, `/impressum` nicht übersetzen; Links behalten DE-`href`s
- Kein Auto-Redirect nach `Accept-Language`; kein Cookie/`localStorage` in v1
- Desktop-Pin-Choreografie eingefroren — keine Änderungen an GSAP-Pin-Hooks/`breakpoints.ts`
- Beide Dictionaries: `satisfies Dictionary`; ID-Parity per `scripts/check-i18n.mjs`
- Hash best-effort beim Toggle; kein pixelgenauer Scroll-Restore
- Außerhalb Home: Section-Links und Logo immer zur DE-Home
- Working directory for commands: `portfolio/` unless noted
- Commits: only when the user explicitly asks (do not auto-commit)

```js
function extractRecordKeys(src, marker) {
  const i = src.indexOf(marker);
  if (i < 0) throw new Error(`marker missing: ${marker}`);
  const slice = src.slice(i, i + 2500);
  return [...slice.matchAll(/^\s{2,6}([a-z0-9-]+):\s*\{/gm)].map((m) => m[1]);
}

const markers = [
  ["services items", "items: {", ["software", "automation", "ai", "website"]],
```

```tsx
function toggleHref(target: Locale) {
  const hash = typeof window !== "undefined" ? window.location.hash : "";
  if (!isHome) return target === "en" ? "/en" : "/";
  const base = target === "en" ? "/en" : "/";
  return `${base}${hash}`; // hash best effort
}
```
